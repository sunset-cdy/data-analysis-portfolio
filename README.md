# 岑登英 · 数据分析作品集

面向「数据分析 / 数据运营实习生」岗位的项目作品集，包含 3 个可讲的项目 + 1 套 SQL 取数练习。

> **项目性质**：淘宝用户行为分析（2 人课程小组）、电影偏好分析（3 人小组）、轻食健康管理系统（7 人团队，本人为后端之一）、SQL 取数练习（个人）。

## 目录结构

```
作品集\
├── README.md                    ← 本文件（放 GitHub 时用这个仓库首页）
├── 01-淘宝用户行为分析\
│   ├── README.md                ← 项目说明（背景/数据/方法/结论/局限）
│   ├── 淘宝用户行为数据分析.ipynb ← 完整分析过程（含 11 张图）
│   ├── 图表\                    ← 从 notebook 导出的 11 张图
│   └── 原课程报告.docx           ← 原始结课报告
├── 02-电影偏好分析\
│   ├── README.md
│   ├── 代码\                    ← PyQt5 主程序、分析与建模脚本、豆瓣数据集

├── 03-轻食健康管理系统\

    └── README.md                ← 50 题分级取数练习（指向 D:\AI产出\SQL练习）
```

## 三个项目，一句话亮点

| 项目 | 亮点 | 面试可讲 |
|---|---|---|
| 淘宝用户行为分析 | 处理 **1,225 万行**数据，算出 PV/UV、转化漏斗、ARPU/ARPPU、复购率等 6 组电商指标 | 指标体系怎么定义、大促前后对比怎么做 |
| 轻食健康管理系统 | **94 个后端接口 / 23 张表**，JWT 鉴权 + 统一响应 + 集成测试，对接 YOLOv8/协同过滤/LSTM | 接口设计、一对多表设计、鉴权流程、前后端联调 |
| 电影偏好分析 | **K-Means 用户分群 + 协同过滤推荐 + 三种分类器对比**，PyQt5 桌面应用 | 为什么用聚类、模型怎么选、指标偏低怎么解释 |

## 怎么用（投递时）

1. **上传 GitHub**（推荐）：
   - 新建仓库，命名如 `data-analysis-portfolio`
   - 把本文件夹内容上传，README.md 就是仓库首页
   - 简历里加一行：`GitHub：github.com/<你的用户名>/data-analysis-portfolio`
2. 也可以直接打包成 zip 作为作品附件（部分公司接受）

## 注意

- 轻食项目是 **7 人团队项目**，本作品集只呈现后端部分，不包含队友的代码与文档
- 淘宝与电影项目均为课程小组项目（2 人 / 3 人），呈现项目成果；数据为公开数据集与模拟数据
