# 电影观看偏好客户群体分析系统

## 一、项目背景

视频平台需要回答「观众可以分成哪几类人、每类人喜欢什么、怎么给单个用户推片」。本项目用豆瓣电影数据做了三件事：用户分群（聚类）、偏好画像（统计）、推荐与模型对比（分类）。

## 二、数据集

| 项 | 说明 |
|---|---|
| 文件 | `代码\douban_top300_sim.csv` |
| 规模 | **4,522 条**用户-电影评分记录，覆盖 **300 部**影片 |
| 粒度 | user_id × movie_id × 评分（模拟数据，用于方法验证） |

## 三、方法与步骤

1. **特征构建**：按用户聚合其观影类型偏好、平均评分等，形成用户偏好特征矩阵
2. **用户分群**：K-Means 聚类，按类型偏好给每个群体打标签（如高分文艺向、爆米花向等）
3. **偏好画像**：统计各群体在不同电影类型上的平均评分/观影量，输出画像图
4. **推荐**：基于用户的协同过滤（用户相似度用余弦相似度），取相似用户高分影片生成 Top-5 推荐
5. **模型对比**：随机森林、KNN、SVM 三种分类器做多标签分类（预测用户偏好类型），并用交叉验证对比稳定性
6. **桌面应用**：PyQt5 实现「加载 CSV → 自动分析 → 选择用户 → 生成推荐」的交互界面

## 五、局限与改进方向（面试时主动讲，是加分项）

**为什么准确率只有 0.015~0.020？** 因为这是**多标签分类**（一个用户同时喜欢多个类型）且组合数极多，用 subset accuracy（要求所有标签全对）衡量会严重偏低；同时数据只有 4,522 条、特征维度低。

**改进方向**：

1. 换指标：改用 micro-F1 / Hamming loss / 排序类指标（MAP@K）
2. 补数据与特征：扩大样本，用 TF-IDF 构建类型向量，加入评分矩阵的 SVD 分解
3. 推荐部分改用矩阵分解（ALS/SVD）替代用户协同过滤，缓解稀疏性
