# SQL 取数练习（50 题）

面向数据分析实习面试的 SQL 刷题集，全部在 **MySQL 5.7** 上实机验证通过（50 条参考答案 0 报错、均有结果）。

## 内容

| 级别 | 题号 | 知识点 |
|---|---|---|
| L1 单表查询 | Q1–Q10 | SELECT / WHERE / ORDER BY / LIMIT / DISTINCT / BETWEEN / LIKE / 日期函数 |
| L2 聚合分组 | Q11–Q20 | COUNT/SUM/AVG、GROUP BY、HAVING、条件聚合、占比计算 |
| L3 多表连接 | Q21–Q30 | INNER JOIN、LEFT JOIN（找「没有…的」）、自连接、一对多聚合 |
| L4 子查询 | Q31–Q40 | 标量子查询、IN、EXISTS / NOT EXISTS、相关子查询、派生表 |
| L5 窗口函数与面试综合 | Q41–Q50 | Top-N、环比、同比、累计、复购率、留存、条件聚合、订单金额对比 |

## 特点

- **两套写法**：每道窗口函数题同时给出 MySQL 8.0 写法（面试用）和 5.7 可跑写法（本地练）——因为本地环境是 5.7，而面试默认 8.0
- **真实业务口径**：GMV 要排除已取消订单、复购率要先统一定义、占比要乘 100.0 避免整数除法
- **配套练习库**：`sql_practice`（7 张表：部门/员工/客户/商品/订单/订单明细），可一键重建
- **校验脚本**：`build\answers-check.sql` 可批量跑所有答案并检查行列数

## 面试能讲什么

- 「给每个部门取薪资前 3」→ 8.0 用 DENSE_RANK，5.7 用相关子查询计数
- 「复购率」→ 先定义口径（下单 ≥2 次客户 / 下过单客户），再用派生表 + HAVING
- 「环比/同比」→ 8.0 用 LAG，5.7 用自连接错位对齐
- 「一对多 join 后算订单数」→ 必须 COUNT(DISTINCT order_id)
