# 淘宝用户购物行为数据分析

## 一、项目背景

电商平台每天产生海量用户行为数据，如何从行为流水中还原「流量—转化—复购」链路，是数据分析岗的典型场景。本项目对淘宝 2014 年 11 月 18 日 – 12 月 18 日（含双十二大促）的用户行为数据做完整分析，回答三个问题：

1. 流量在什么时间最集中？（日粒度 / 小时粒度 PV、UV）
2. 从浏览到购买，各环节流失多少？（行为漏斗与转化率）
3. 大促对消费的拉动有多大？用户复购特征是怎样的？（ARPU/ARPPU、复购率与复购间隔）

## 二、数据集

| 项 | 说明 |
|---|---|
| 来源 | 公开数据集 Taobao UserBehavior（user_action.csv） |
| 时间范围 | 2014-11-18 ~ 2014-12-18（31 天，含双十二） |
| 数据量 | **12,256,906 行**（约 1,225 万条） |
| 用户数 | 10,000 |
| 商品数 | 2,876,947 |
| 商品类目数 | 8,916 |
| 字段 | user_id、item_id、behavior_type、item_category、time |
| 行为类型 | 1=点击、2=收藏、3=加购、4=购买 |
| 缺失值 | 无 |

## 三、方法与步骤

1. **数据清洗**：检查缺失值（0 缺失）；拆分 `time` 为 date（天）与 hour（小时）；把 ID 类字段转为 object，date 转 datetime，hour 转 int
2. **流量分析**：按天/小时分组统计 PV（行为条数）与 UV（去重用户数）
3. **漏斗分析**：按 behavior_type 汇总，计算 加购/收藏率、点击→购买转化率、加购→购买转化率，并与双十二当天对比
4. **消费指标**：计算 ARPU（每日消费次数 / 日活用户）与 ARPPU（每日购买次数 / 当日购买用户数）
5. **复购分析**：按用户统计购买天数得到购买频次，计算复购率；对相邻两次购买日期求差，得到 40,315 条复购间隔并绘制分布
6. **可视化**：matplotlib / seaborn 输出 11 张图

## 四、核心结论

| 指标 | 平日 | 双十二（12-12） |
|---|---|---|
| 日 PV | 约 40 万 | **691,712** |
| 日 UV | 约 6,400 | **7,720** |
| 点击→购买转化率 | 1.04% | **2.38%** |
| 收藏+加购→购买转化率 | 20.5% | **43.6%** |
| ARPU | 约 0.55 | **1.98**（约 3.6 倍） |
| ARPPU | 约 2.3 | **3.91** |

- 全周期行为量：点击 **11,550,581**、收藏 242,556、加购 343,564、购买 120,205
- 加购/收藏率 5.07%，点击→购买 1.04%，加购/收藏→购买 20.5%
- 复购率 **87.2%**（8,886 名购买用户中，购买天数 ≥2 的用户占比）
- 流量高峰集中在 **20:00–22:00**（全天 PV 前三的小时：21 点约 109 万、22 点约 109 万、20 点约 94 万）；双十二当天单小时 PV 峰值 5.13 万（22 点）

**业务解读**：大促同时拉升了流量与转化——UV 只涨约 20%，但 PV 涨 73%、ARPU 涨 260%，说明增量主要来自「同批用户买得更多」，而非新用户涌入。因此大促选品与凑单机制比拉新更关键。

## 五、局限与改进方向

1. 数据为 2014 年公开数据集，结论仅用于方法验证
2. 只有行为流水，没有金额字段，ARPU 用「购买次数」近似
3. 可继续做：RFM 用户分层、留存 cohort（首购后 7/30 天回访）、用 SQL 复现核心指标（窗口函数做 Top-N 与环比）
