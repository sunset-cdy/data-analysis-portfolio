# 轻食健康管理系统（后端开发）

> 说明：本项目为 **7 人团队项目（工学结合，6 周）**，本人担任**后端工程师**。本文件只写本人负责的部分，不包含队友代码与文档。

## 一、项目概述

面向轻食/减脂人群的微信小程序 + PC 管理后台系统，核心能力：

- 健康打卡（饮水、运动、心情等）
- 饮食记录 + **YOLOv8 菜品识别**自动算营养
- 营养统计与健康趋势（**LSTM** 预测）
- 食谱推荐（**协同过滤**）
- 社区、文章内容模块
- PC 管理后台

我的角色在后端（2 名后端之一），负责接口开发、数据库设计与文档、算法服务对接、部署联调。

## 二、技术栈

| 层级 | 技术 |
|---|---|

## 五、面试可讲的 4 个技术点

1. **一对多表设计**：`users 1—N checkins / diet_records`，`diet_records 1—N food_items`，营养统计表按天聚合冗余存储（用空间换查询速度）
2. **JWT 鉴权流程**：登录签发 access + refresh token，请求头携带 token，装饰器统一校验并在 request 上下文注入当前用户
3. **统一响应与异常处理**：`response.py` 统一返回格式，`error_handler.py` 捕获业务异常并映射错误码，前端只需处理一套结构
4. **识菜数据链路**：图片上传 → 算法服务返回菜名与置信度 → 按菜名映射营养表 → 生成 diet_record + 更新 daily_nutrition → 前端统计页刷新
