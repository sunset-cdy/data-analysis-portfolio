# 轻食健康管理系统（后端开发）

> **项目性质**：7 人团队项目（工学结合，6 周）。本人担任后端开发（2 名后端之一），负责 **RESTful 接口开发、接口文档与前后端联调、算法服务对接**。
>
> **不属于本人的部分**：数据库表结构设计 / 建表脚本 / 种子数据（队友负责）、集成测试与系统测试（队友负责）、Docker 部署（队友负责）。本文件不包含队友的代码与文档。

## 一、项目概述

面向轻食/减脂人群的微信小程序 + PC 管理后台系统，核心能力：

- 健康打卡（饮水、运动、心情等）
- 饮食记录 + **YOLOv8 菜品识别**自动算营养
- 营养统计与健康趋势（**LSTM** 预测）
- 食谱推荐（**协同过滤**）
- 社区、文章内容模块
- PC 管理后台

## 二、技术栈（团队）

| 层级 | 技术 |
|---|---|
| 前端 | Vue3 + uni-app（微信小程序 / H5）、Element Plus（PC 后台） |
| 后端 | Python 3.10 + Flask + JWT + SQLAlchemy |
| 数据库 | MySQL 8.0（表结构由队友设计） |
| 算法服务 | YOLOv8（菜品识别）、协同过滤（食谱推荐）、LSTM（健康趋势） |
| 部署 | Docker Compose + Nginx + Gunicorn（部署由队友负责） |

## 三、我做了什么

| 项 | 内容 |
|---|---|
| RESTful 接口 | 基于 Flask 开发业务接口。项目共 **94 个路由**，本人承担**大部分**，覆盖认证、打卡、饮食、营养、食物、食谱、文章、社区、统计等模块 |

## 四、团队情况（供面试说明用）

- 团队 7 人：前端 2、后端 2、算法 2、运维测试 1、项目经理 1
- 本人是 2 名后端之一
- 数据库设计、测试、部署由其他成员负责；本人专注接口开发与联调

## 五、面试可讲的 3 个技术点

1. **接口分层与统一响应**：路由 → service → model 分层；`response.py` 统一返回格式，`error_handler.py` 统一异常映射，前端只需处理一套结构
2. **JWT 鉴权流程**：登录签发 access + refresh token，请求头携带 token，装饰器统一校验并在 request 上下文注入当前用户
3. **识菜数据链路**：图片上传 → 算法服务返回菜名与置信度 → 按菜名映射营养表 → 生成饮食记录 + 更新每日营养 → 前端统计页刷新
